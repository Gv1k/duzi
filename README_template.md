# 🍜 肚子说了算｜AI 选餐助手

> 解决西南交通大学学生"今天吃啥"选择困难症的 AI 小工具

---

## 📌 一句话介绍

**肚子说了算**是一个面向西南交通大学学生的 H5 选餐 App，用 AI 根据你当下的心情和口味偏好，从校内 45+ 家餐厅中帮你做决定。

---

## 😩 解决的问题

> "又到饭点了，不知道吃啥，翻来翻去还是关掉了美团。"

- 选项太多反而更难选
- 朋友推荐的不符合自己当下口味
- 外卖平台推荐是广告，不是真推荐

---

## ✨ 核心功能

| 功能 | 说明 |
|------|------|
| 🎴 三选一推荐 | 每次生成 3 张餐厅卡片，支持单独刷新 |
| 💬 AI 理由 | 每张卡片附上 AI 为你选它的理由 |
| 😶 没胃口模式 | 点"没胃口"进入特殊流程，换个思路推荐 |
| 🗂️ 分类筛选 | 支持按口味、价格区间、距离筛选 |

---

## 🛠️ 技术栈

```
前端        HTML5 + CSS3 + Vanilla JS（单文件 index.html）
AI 接口     DeepSeek API（推荐理由生成）
数据库      Supabase（餐厅数据，45+ 家，18 个分类）
部署        —（本地 / 静态托管）
开发工具    Cursor + Claude
```

## 🧠 我的思考

### 为什么做这个？
选餐困难本质上是"选择悖论"——选项越多越焦虑。AI 的价值不是给你更多选择，而是**帮你减少选择**。

### 技术决策
选择单文件 H5 而非 React，是因为目标场景是手机扫码直接用，不需要复杂工程化，部署门槛越低越好。

### 踩过的坑
- DeepSeek API 响应时间不稳定，加了 loading 状态和超时兜底
- Supabase 免费套餐有并发限制，做了本地缓存优化
